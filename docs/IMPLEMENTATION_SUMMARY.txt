```

  - Package templates (4 sessions, 8 sessions, etc.)

  - Session assignments (which trainer, which student, dates)
```

## 🎯 Key Features

### Session Package Management
- Create reusable packages (e.g., "4-Session Starter")
- Define duration, price, session count
- Activate/deactivate packages

### Student Session Assignment
- Assign trainer sessions to any member
- Auto-calculate expiration dates (1 session/week)
- Track total and remaining sessions
- Link to trainer and optional package
- Add session notes and context

### Individual Session Tracking
- Auto-creates individual logs for each session
- Track status: PENDING → SCHEDULED → COMPLETED
- Also support: CANCELLED, RESCHEDULED, NO_SHOW
- Record location format (IN_PERSON or VIDEO)

### Admin Interface
- Integrated into member profile
- Tab-based interface (Sessions | Packages)
- Modal-based add/edit operations
- Expandable/collapsible section
- Visual status indicators
- Fully responsive design

### Security & Access Control
- JWT authentication required
- Superuser & Staff: Full management
- Trainer: Can update session logs only
- Student: View-only access

## 💡 Usage Example

### Scenario: Assign 8 sessions to member "Alex" with trainer "Mike"

1. Go to member profile for "Alex"
2. Click "Manage Trainer Sessions"
3. Click "+ Add New Session Package"
4. Select Trainer: "Mike Johnson"
5. Sessions: 8
6. Start Date: Oct 1, 2024
7. Expiration: Dec 31, 2024 (auto-calculated as Nov 26, manual adjusted)
8. Notes: "Marathon prep training"
9. Click "Save"

✅ Done! 8 sessions created and tracking begins

### Track Progress:
1. Click "View Details"
2. See 8 individual session logs
3. Update status as sessions occur:
   - Session 1: PENDING → SCHEDULED → COMPLETED
   - Session 2: PENDING → SCHEDULED → COMPLETED
   - ... etc
